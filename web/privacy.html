__ASSISTANT_NAME__

__ASSISTANT_NAME__ is a private voice assistant built for and used by one person, its owner. It is not offered to the public, and the app is locked behind an access phrase.

Email (Google and Microsoft)

With the owner's sign-in, __ASSISTANT_NAME__ can search and read the owner's own mailboxes and save draft emails into them. It cannot send email. Email content is fetched only when the owner asks a question that needs it. It is used only to answer that question and is not stored, sold, shared or used for advertising or model training.

Calendar

The owner's phone app reads the next seven days of the phone's calendar and sends them with a question. They are not stored.

Where data goes

Questions are processed by the Anthropic API (to write an answer) and ElevenLabs (to speak it). Recent conversation and facts the owner asks it to remember are kept in the owner's own AWS account. Sign-in tokens are kept encrypted in AWS Secrets Manager in that account.

Google user data

__ASSISTANT_NAME__'s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from the Google or Microsoft account's security settings. Revoking it stops __ASSISTANT_NAME__ from reading that mailbox immediately.
